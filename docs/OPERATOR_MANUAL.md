# AI CCTV 안전관제 시스템 — 운영자 매뉴얼

> 대상: **운영자(admin 역할)** · 기준 브랜치: `FE-polish` · 최종 갱신: 2026-06

---

## 1. 개요

### 1.1 시스템 소개
AI CCTV 안전관제 시스템은 현장 CCTV를 실시간 관제하고, AI가 영상 속 안전 위험을 자동 감지·알림하는 웹 서비스입니다. 운영자(admin)는 일반 사용자의 모든 조회 기능에 더해, **CCTV 채널·안전 매뉴얼·점검 체크리스트·현장 계정**을 직접 관리합니다.

### 1.2 매뉴얼 목적
이 매뉴얼은 **운영자(admin 역할)** 의 **관리 업무**를 화면 단위로 설명합니다. 로그인·관제·검색·구역/체크리스트 **조회** 등 일반 사용 방법은 **사용자 매뉴얼**을 참고하고, 본 문서는 **운영자 전용(관리) 화면**에 집중합니다.

### 1.3 운영자 권한
- 계정은 **user(조회)** 와 **admin(관리)** 2단계입니다. admin은 user의 모든 기능 + 아래 관리 기능을 수행합니다.
- 모든 계정·데이터는 **하나의 현장(site)** 에 소속되어 **현장 단위로 격리**됩니다. admin도 **자기 현장**만 관리합니다(타 현장 조회·관리 불가).
- admin이 할 수 있는 관리: **채널 추가/수정/삭제 · 구역 등록 · 매뉴얼 분석/체크리스트 확정·편집 · 리포트 조회 · 시스템 현황 조회 · 현장 계정(user/admin) 생성·초기화·삭제**.

### 1.4 계정·비밀번호 운영 정책 (중요)
- 현장과 **최초 admin 계정**은 시스템 설치 시 백엔드에서 **자동 생성(seed)** 됩니다.
- 이후 계정은 **admin이 관리(`ADM-001`) 화면에서 생성**합니다. 계정 생성 시 시스템이 **임시 비밀번호를 자동 발급**해 화면에 1회 표시합니다 → 담당자에게 안전하게 전달하세요.
- 사용자는 **첫 로그인 시 비밀번호를 강제로 변경**합니다. admin은 임시 비밀번호를 알 수 없으며(교체 후), 분실 시 **초기화**로 새 임시 비밀번호를 재발급합니다.

## 2. CCTV 안전관제 운영·관리 개요

### 2.1 업무 영역 설명
운영자는 다음 업무를 수행합니다.
- **채널 관리**: CCTV(RTSP/웹캠 등)를 채널로 등록·수정·삭제하고 구역에 배정합니다.
- **안전 기준 관리**: 안전 매뉴얼(PDF)을 업로드·분석해 **AI가 점검할 체크리스트**를 만들고 편집·확정합니다. 구역(zone)도 등록합니다.
- **모니터링**: 시스템 현황(현장/기기/계정)과 안전 리포트(통계)를 확인합니다.
- **계정 관리**: 자기 현장의 user/admin 계정을 생성·초기화·삭제합니다.

### 2.2 로그인 절차
1. 시스템 주소로 접속해 로그인 화면에서 **admin 계정**으로 로그인합니다(절차는 사용자 매뉴얼 `LGN-001`/`PWD-001`과 동일, 최초 로그인 시 비밀번호 변경).
2. 관제(월) 홈에서 우상단 **[콘솔]** 을 눌러 콘솔 창을 엽니다.
3. 콘솔 사이드바에 admin 전용 메뉴(**리포트·현황·관리**)와 공통 메뉴(검색·구역·메뉴얼)가 표시됩니다.

> [화면 캡처: admin 로그인 후 콘솔 사이드바 — 검색/구역/메뉴얼 + (구분선) 리포트/현황/관리]

### 2.3 화면 목록 (운영자 전용·관리 화면)

| 메뉴 Level1 | 메뉴 Level2 | 화면 ID | 화면명 | 비고 |
|---|---|---|---|---|
| 채널 | 채널 관리 | `CHN-001` | 채널 등록/수정/삭제 | 관제(월)에서 수행 |
| 안전기준 | 구역 등록 | `MNL-101` | 구역(zone) 등록 | 메뉴얼 화면 |
| 안전기준 | 체크리스트 | `MNL-102` | 매뉴얼 분석·체크리스트 확정/편집 | 메뉴얼 화면 |
| 모니터링 | 리포트 | `RPT-001` | 안전 이벤트 리포트 | `adminOnly` |
| 모니터링 | 현황 | `STS-001` | 시스템 현황 | `adminOnly` |
| 계정 | 관리 | `ADM-001` | 현장 계정 관리 | `adminOnly` |

> 위 외의 화면(관제·검색·클립 상세·프로필 등)은 **사용자 매뉴얼**을 참고하세요. admin도 동일하게 사용합니다.

## 3. 운영·관리 매뉴얼

### 3.1 채널 관리

#### 3.1.1 `CHN-001` 채널 등록 / 수정 / 삭제
- **목적**: CCTV 카메라를 **채널(영상 한 칸)** 로 등록해 관제 화면에 띄우고, 구역에 배정합니다.
- **화면 위치**: **관제(월) 화면(`WAL-001`)** 의 2×2 그리드. 빈 칸 클릭 → **채널 등록 모달**, 기존 카드에 마우스를 올리면 **[수정]/[삭제]** 버튼.
- **채널 등록 절차**:
  1. 관제(월)에서 **빈 슬롯**을 클릭하면 “슬롯 N에 채널 등록” 모달이 열립니다(해당 슬롯은 `camN`으로 매핑).
  2. **채널명**(필수, 예: “정문 CCTV”)을 입력합니다.
  3. **소스 타입**을 선택합니다.
     - **URL**: RTSP/HTTP 주소 입력(`rtsp://… ` 또는 `http://…`). RTSP는 백엔드가 MediaMTX로 끌어와 재생합니다.
     - **웹캠**: 브라우저 웹캠을 송출(WHIP)해 재생합니다.
     - (파일/유튜브 소스는 URL란에 경로/링크로 등록)
  4. **구역**을 선택합니다(미리 `MNL-101`에서 등록한 구역 목록에서 선택, 없으면 “없음”).
  5. 저장하면 채널이 그리드에 추가되고 영상이 재생됩니다.
- **수정/삭제**: 채널 카드에 마우스를 올려 **[수정]**(채널명·URL·구역 변경) 또는 **[삭제]** 를 누릅니다.
- **주요 동작/유의사항**:
  - 등록 시 내부적으로 **MediaMTX 경로 + DB + Redis** 에 동시에 반영됩니다. MediaMTX 경로는 현장 격리를 위해 `{현장ID 앞 8자}_{채널명}` 으로 생성됩니다.
  - **권한**: 채널 등록/수정/삭제는 **admin 전용**입니다(user는 보기만).
  - 채널을 구역에 배정하면, 해당 구역의 체크리스트가 그 카메라의 AI 판단 기준으로 사용됩니다.
- **화면 이동**: 모달 저장/취소 → 관제(월)로 복귀.

> [화면 캡처: 채널 등록 모달 — 채널명, 소스 타입(URL/웹캠), URL, 구역 선택]

### 3.2 안전 기준 관리 (메뉴얼 화면)

> 메뉴얼 화면(`/manual`)은 admin에게 **① 구역 정보 · ② 메뉴얼 파일 관리(분석·체크리스트) · ③ 현재 적용 체크리스트** 세 영역으로 보입니다.

#### 3.2.1 `MNL-101` 구역(Zone) 등록
- **목적**: 현장 구획(구역)을 등록합니다. 구역을 먼저 등록하면, 매뉴얼 분석 시 **구역별 체크리스트가 자동 생성**됩니다.
- **화면 구성**: 메뉴얼 화면 상단 “구역 정보” 영역 — [샘플 다운로드], CSV/XLSX 업로드 영역, [구역 등록], 등록된 구역 칩 목록.
- **사용 절차**:
  1. **[샘플 다운로드]** 로 양식을 받습니다(컬럼: `zone`, `description`, `비고`).
  2. 구역 정보를 채운 **CSV/XLSX**(최대 5MB)를 드래그하거나 클릭해 업로드합니다.
  3. **[구역 등록]** 을 누르면 구역 목록이 칩으로 표시됩니다.
- **주요 동작/유의사항**: 구역명은 채널 배정(`CHN-001`)·체크리스트 구역 분할에 사용됩니다. 같은 현장 기준으로 저장됩니다.

> [화면 캡처: 구역 정보 — 샘플 다운로드, CSV/XLSX 업로드, 등록된 구역 칩]

#### 3.2.2 `MNL-102` 매뉴얼 분석 · 체크리스트 확정/편집
- **목적**: 안전 매뉴얼(PDF)을 업로드·분석해 **AI 점검 체크리스트**를 만들고, 직접 편집·확정합니다. 확정된 체크리스트가 VLM(영상 분석 AI)의 판단 기준이 됩니다.
- **화면 구성**: “메뉴얼 파일 관리” 영역(PDF 업로드 → 분석 결과 검토) + “구역별 확인 항목” + “현재 적용 중인 체크리스트”.
- **사용 절차(업무 흐름)**:
  1. **PDF 업로드**: 안전 문서(PDF, 최대 20MB)를 드래그/클릭해 올립니다.
  2. **[분석 시작]**: AI가 문서를 분석해 **STATIC(정적)·DYNAMIC(동적)** 체크리스트 초안을 생성합니다.
  3. **검토·편집(ChecklistReview)**: 각 항목에 마우스를 올려 **연필 아이콘으로 문구 수정**, **삭제**, **[+ 항목 추가]** 로 직접 편집합니다.
  4. **재생성(선택)**: 하단 입력란에 자연어 피드백(예: “낙상 항목을 더 구체적으로”)을 적고 **[재생성]** 하면 AI가 반영해 다시 만듭니다.
  5. **구역별 확인 항목**: 구역을 등록해 두었다면 구역별 초안이 함께 표시되며, 동일하게 인라인 편집할 수 있습니다.
  6. **[확정]**: 최종 항목을 확정하면 AI에 즉시 반영됩니다. 확정 시 **편집된 항목 기준으로 카테고리(위험 유형) 코드가 자동 재산정**됩니다.
- **현재 적용 중인 체크리스트**: 확정본을 **[전체]/[구역명]** 버튼으로 구역별로 조회합니다(실제 AI가 쓰는 기준).
- **주요 동작/유의사항**:
  - 분석·재생성은 AI(LLM) 호출이라 수 초 걸릴 수 있습니다. 실패 시 “다시 시도” 안내가 표시됩니다.
  - **수정·확정 권한은 admin 전용**입니다.
- **화면 이동**: 동일 화면 내에서 진행(분석→편집→확정→적용 조회).

> [화면 캡처: 메뉴얼 분석 — PDF 업로드/분석 시작, STATIC/DYNAMIC 인라인 편집, 구역별 확인 항목, 확정 버튼]

### 3.3 모니터링

#### 3.3.1 `RPT-001` 안전 이벤트 리포트
- **목적**: 자기 현장의 안전 이벤트를 기간별로 집계해 추세를 파악합니다(일일/주간 보고용).
- **화면 구성**: 상단 기간 토글 **[최근 7일]/[최근 30일]**, 누적 총계, **위험도 분포**(막대), **일자별 추이**(막대), **시간대별(0–23시)**(막대), **이벤트 多 카메라 Top**(목록).
- **사용 절차**: 기간을 선택하면 차트가 갱신됩니다. 위험도·시간대·카메라 분포로 “언제·어디서 위험이 잦은지”를 확인합니다.
- **주요 동작/유의사항**: **admin 전용(`adminOnly`)**. 데이터는 본인 현장으로 한정됩니다.

> [화면 캡처: 리포트 — 기간 토글, 위험도/일자/시간대 차트, 카메라 Top]

#### 3.3.2 `STS-001` 시스템 현황
- **목적**: 현장 운영 상태를 한 화면에서 점검합니다.
- **화면 구성(3개 섹션)**:
  - **현장 요약**: 카메라 수·계정 수·오늘 이벤트 수(위험도 분포). “오늘 이벤트 N건 ›” 을 누르면 **오늘 이벤트 상세 모달**이 열립니다(시각·채널·위험도·내용).
  - **CCTV 기기 상태**: 채널별 **온라인/오프라인** 과 마지막 프레임 수신 시각. (최근 프레임 수신이 임계값 이내면 온라인)
  - **계정 현황**: 현장 계정의 role, **초기 비밀번호 미변경 여부**, **마지막 로그인** 시각.
- **사용 절차**: 기기 오프라인·미접속 계정 등을 점검하고, “오늘 이벤트”를 눌러 당일 상황을 드릴다운합니다.
- **주요 동작/유의사항**: **admin 전용**. 사이드바 상단 **상태 점등(온라인 n/N)** 과 연동되는 기기 상태를 상세로 보여 줍니다.
- **화면 이동**: “오늘 이벤트 ›” → 오늘 이벤트 상세 모달(닫기).

> [화면 캡처: 시스템 현황 — 현장 요약, CCTV 기기 상태(온라인/오프라인), 계정 현황, 오늘 이벤트 모달]

### 3.4 계정 관리

#### 3.4.1 `ADM-001` 현장 계정 관리
- **목적**: 자기 현장의 **user/admin 계정**을 생성·초기화·삭제합니다.
- **화면 구성**: “{현장명} — 계정” 패널 — 계정 목록(username·role·액션), **[계정 추가]**, 초기 비밀번호 표시 모달.
- **사용 절차**:
  - **계정 생성**: **[계정 추가]** → username 입력, **role 선택(user/admin)** → [추가]. 생성되면 **초기 비밀번호 모달**이 1회 표시됩니다 → 담당자에게 전달하세요.
  - **비밀번호 초기화**: 목록의 해당 계정에서 초기화 → 새 임시 비밀번호가 모달로 표시됩니다(사용자는 다음 로그인 시 강제 변경).
  - **계정 삭제**: 목록에서 삭제(본인 계정은 삭제 불가).
- **주요 동작/유의사항**:
  - **admin 전용(`adminOnly`)**. 생성·관리 대상은 **자기 현장** 계정으로 한정됩니다.
  - 초기 비밀번호는 **생성/초기화 직후 한 번만** 표시됩니다. 닫으면 다시 볼 수 없으니 그 자리에서 전달하세요.
- **화면 이동**: 동일 화면 내 모달 처리.

> [화면 캡처: 계정 관리 — 계정 목록, 계정 추가(role 선택), 초기 비밀번호 모달]

## 부록 A. 운영 체크리스트 (설치~운영)
1. 설치 직후 **seed된 admin 계정**으로 로그인 → 비밀번호 변경.
2. **구역 등록(`MNL-101`)** → **채널 등록(`CHN-001`)** → 채널을 구역에 배정.
3. **안전 매뉴얼 업로드·분석·확정(`MNL-102`)** 으로 점검 기준 설정.
4. 현장 담당자 **계정 발급(`ADM-001`)** → 임시 비밀번호 전달.
5. 일상 운영: **현황(`STS-001`)** 으로 기기/계정 점검, **리포트(`RPT-001`)** 로 추세 확인.

## 부록 B. 권한 요약 (admin vs user)
| 기능 | user | admin |
|---|---|---|
| 관제·검색·구역·메뉴얼 **조회** | ✅ | ✅ |
| 채널 추가/수정/삭제 (`CHN-001`) | ❌ | ✅ |
| 구역 등록·체크리스트 확정/편집 (`MNL-101/102`) | ❌ | ✅ |
| 리포트·현황 (`RPT-001`/`STS-001`) | ❌ | ✅ |
| 계정 생성·초기화·삭제 (`ADM-001`) | ❌ | ✅ |

## 부록 C. 화면 ID 색인 (운영자)

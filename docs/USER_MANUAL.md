# AI CCTV 안전관제 시스템 — 사용자 매뉴얼

> 대상: **일반 사용자(user 역할)** · 기준 브랜치: `FE-polish` · 최종 갱신: 2026-06

---

## 1. 개요

### 1.1 시스템 소개
AI CCTV 안전관제 시스템은 현장에 설치된 CCTV 영상을 실시간으로 보여주고, AI가 영상 속 **안전 위험(화재·연기·낙상, 안전수칙 위반 등)** 을 자동으로 감지해 알려 주는 웹 서비스입니다. 사용자는 웹 브라우저만으로 실시간 영상 관제, 과거 이벤트 검색, 구역별 점검 항목 확인을 할 수 있습니다.

### 1.2 매뉴얼 목적
이 매뉴얼은 **일반 사용자(user 역할)** 가 시스템에 처음 접속해 일상적인 관제·조회 업무를 수행할 수 있도록, 각 화면의 목적과 사용 방법을 화면 단위로 설명합니다. (채널 등록, 체크리스트 편집, 계정 관리 등 **관리 기능은 운영자 매뉴얼**을 참고하세요.)

### 1.3 사용자 역할(권한) 안내
- 본 시스템의 계정은 **user(일반 사용자)** 와 **admin(운영자)** 2단계로 나뉩니다.
- 모든 계정은 **하나의 현장(site)** 에 소속되며, 화면에 보이는 영상·이벤트·점검 항목은 **본인 현장의 데이터로 한정**됩니다.
- **user 역할**은 “보기(조회)” 권한입니다. 영상 관제·검색·구역/체크리스트 조회는 가능하지만, 채널이나 체크리스트를 **수정·등록할 수는 없습니다**.

### 1.4 용어
| 용어 | 설명 |
|---|---|
| 관제(월, Wall) | 4개 채널을 한 화면에 보여 주는 실시간 영상 홈 화면 |
| 콘솔(Console) | 검색·구역·메뉴얼·프로필 등 부가 기능을 모아 둔 별도 창 |
| 채널 | CCTV 카메라 한 대(= 영상 한 칸) |
| 이벤트 | AI가 감지한 안전 위험 1건 (화재·낙상·수칙 위반 등) |
| 위험도 | 이벤트의 심각도 — 심각(critical)·높음(high)·낮음(low)·정상(none) |
| 구역(Zone) | 현장 내 구획(예: 크레인 작업구역). 구역별 점검 항목이 있음 |
| 체크리스트 | AI가 영상에서 확인하는 안전 점검 항목 목록 |

## 2. CCTV 안전관제(조회) 개요

### 2.1 업무 영역 설명
일반 사용자는 다음 업무를 수행합니다.
- **실시간 관제**: 현장 CCTV를 4분할 화면으로 실시간 모니터링하고, 위험 발생 시 즉시 알림을 받습니다.
- **이벤트 조회**: 지나간 위험 상황을 자연어로 검색하고, 캡처(스냅샷)로 상세를 확인합니다.
- **안전 점검 확인**: 구역별로 AI가 점검하는 항목과 현재 적용 중인 체크리스트를 조회합니다.
- **내 계정 관리**: 비밀번호 변경, 화면 테마 변경, 로그아웃을 합니다.

### 2.2 로그인 절차
1. 브라우저에서 시스템 주소로 접속하면 **로그인 화면**이 표시됩니다.
2. 운영자(admin)에게 발급받은 **아이디(username)** 와 **임시 비밀번호**를 입력하고 **로그인**합니다.
3. **최초 로그인 시** 보안을 위해 **비밀번호 변경 화면**으로 자동 이동합니다. 새 비밀번호(8자 이상, 영문+숫자 포함)로 변경해야 다음 화면으로 진행됩니다.
4. 변경 후 자동으로 **관제(월)** 홈 화면이 표시됩니다.

> [화면 캡처: 로그인 화면 — 아이디/비밀번호 입력란과 로그인 버튼]

### 2.3 화면 목록

| 메뉴 Level1 | 메뉴 Level2 | 화면 ID | 화면명 | 비고 |
|---|---|---|---|---|
| 접속 | 로그인 | `LGN-001` | 로그인 | 공개(인증 불필요) |
| 접속 | 비밀번호 변경 | `PWD-001` | 비밀번호 변경 | 최초 로그인 시 강제 |
| 관제 | 관제(월) | `WAL-001` | 실시간 관제 화면 | 홈 화면 |
| 조회 | 검색 | `SCH-001` | 이벤트 검색 | 콘솔 |
| 조회 | 클립 상세 | `SCH-002` | 클립(이벤트) 상세 | 콘솔 |
| 안전점검 | 구역 | `ZON-001` | 구역별 점검 현황 | 콘솔 |
| 안전점검 | 메뉴얼 | `MNL-001` | 적용 체크리스트 조회 | 콘솔(조회 전용) |
| 내 계정 | 프로필 | `PRF-001` | 프로필 | 콘솔 |

## 3. CCTV 안전관제(조회) 매뉴얼

### 3.1 접속 / 계정

#### 3.1.1 `LGN-001` 로그인
- **목적**: 발급받은 계정으로 시스템에 접속합니다.
- **화면 구성**: 아이디 입력란, 비밀번호 입력란, [로그인] 버튼.
- **사용 절차**:
  1. 아이디·비밀번호를 입력합니다.
  2. [로그인]을 클릭합니다.
  3. 인증에 성공하면 관제(월) 홈으로 이동합니다(최초 로그인은 `PWD-001`로 이동).
- **주요 동작/유의사항**:
  - 아이디 또는 비밀번호가 틀리면 “아이디 또는 비밀번호가 올바르지 않습니다” 메시지가 표시됩니다(보안상 어느 쪽이 틀렸는지는 알려 주지 않습니다).
  - 로그인 시도는 **분당 5회로 제한**됩니다. 초과 시 잠시 후 다시 시도하세요.
  - 인증 정보는 브라우저 쿠키로 안전하게 보관되며, 일정 시간(근무 1교대) 후 자동 만료됩니다.
- **화면 이동**: 성공 → `WAL-001`(또는 최초 로그인 시 `PWD-001`).

> [화면 캡처: 로그인 폼]

#### 3.1.2 `PWD-001` 비밀번호 변경
- **목적**: 임시 비밀번호를 본인만 아는 비밀번호로 바꿉니다. **최초 로그인 시 반드시** 거칩니다.
- **화면 구성**: 현재 비밀번호 입력란, 새 비밀번호 입력란(8자 이상·영문+숫자), [변경] 버튼.
- **사용 절차**:
  1. 현재(임시) 비밀번호를 입력합니다.
  2. 새 비밀번호를 규칙(8자 이상, 영문+숫자 포함)에 맞게 입력합니다.
  3. [변경]을 클릭합니다.
- **주요 동작/유의사항**: 변경 전에는 다른 화면으로 이동할 수 없습니다. 변경 완료 후 관제(월)로 이동합니다. 평상시에는 **프로필(`PRF-001`)** 에서 언제든 비밀번호를 변경할 수 있습니다.
- **화면 이동**: 성공 → `WAL-001`.

### 3.2 관제

#### 3.2.1 `WAL-001` 실시간 관제 화면 (관제/월)
- **목적**: 현장 CCTV 4대를 한 화면에서 실시간으로 보고, 위험 발생 시 즉시 알림을 받습니다. 로그인 직후 보이는 **홈 화면**입니다.
- **화면 구성**:
  - **상단 헤더**: 좌측 `현재 온라인 채널 수 / 4`, 중앙 **실시간 시계**, 우측 **[콘솔]** 버튼·**[알림]** 토글.
  - **본문**: **2×2 채널 그리드**(최대 4개). 각 칸은 실시간 영상이 재생되는 **채널 카드**이며, 비어 있는 칸은 회색 점선으로 표시됩니다.
  - **알림 패널**: [알림]을 켜면 우측에 최근 알림 히스토리가 나타납니다.
- **사용 절차**:
  1. 로그인하면 자동으로 이 화면이 표시되고, 등록된 채널의 영상이 자동 재생됩니다.
  2. 우상단 **[콘솔]** 을 누르면 검색·구역·메뉴얼·프로필이 있는 **콘솔 창이 새 창으로** 열립니다(관제 화면은 그대로 유지됨).
  3. **[알림]** 토글로 알림 히스토리 패널을 켜고 끌 수 있습니다.
- **주요 동작/이벤트**:
  - **실시간 알림 토스트**: AI가 위험을 감지하면 화면 **우하단에 알림 토스트**가 자동으로 떠 채널·위험도·내용을 알려 줍니다(모든 화면 공통).
  - **영상 재생**: 영상은 WebRTC로 실시간 송출됩니다. 네트워크 상태에 따라 약간의 지연이 있을 수 있습니다.
  - **(user 권한)** 빈 칸을 눌러 **채널을 추가하는 기능은 admin 전용**입니다. user는 보기만 가능합니다.
- **화면 이동**: [콘솔] → 콘솔 창(검색/구역/메뉴얼/프로필 등).

> [화면 캡처: 관제(월) — 2×2 영상 그리드, 상단 채널 수·시계·콘솔/알림 버튼, 우하단 알림 토스트]

### 3.3 조회 / 검색

#### 3.3.1 `SCH-001` 이벤트 검색
- **목적**: 과거에 감지된 이벤트를 **자연어**로 검색합니다(예: “어제 낙상”, “정문 화재”).
- **화면 구성**:
  - **검색창(SearchBar)**: 찾고 싶은 내용을 문장으로 입력.
  - **빠른 날짜 필터**: 오늘/최근 7일 등 버튼.
  - **자연어 필터 칩**: 검색어에서 자동 감지한 조건(기간·채널 등)을 “검색어에서 감지:” 칩으로 표시.
  - **채널 필터**: 특정 채널만 보기.
  - **결과 목록(ResultList)**: 이벤트 카드(썸네일·위험도·채널·시각·요약).
- **사용 절차**:
  1. 검색창에 찾을 내용을 자연어로 입력하고 검색합니다.
  2. 필요하면 날짜/채널 필터로 범위를 좁힙니다.
  3. 결과 카드를 클릭하면 **클립 상세(`SCH-002`)** 로 이동합니다.
- **주요 동작/유의사항**:
  - 검색은 단순 키워드 일치가 아니라 **의미 기반(임베딩) 검색**이라, 표현이 조금 달라도 비슷한 이벤트를 찾아 줍니다.
  - 검색 결과는 **본인 현장**의 이벤트로 한정됩니다.
- **화면 이동**: 결과 카드 → `SCH-002`.

> [화면 캡처: 검색 화면 — 검색창, 날짜/필터 칩, 결과 카드 목록]

#### 3.3.2 `SCH-002` 클립(이벤트) 상세
- **목적**: 선택한 이벤트의 **캡처 이미지(스냅샷)** 와 상세 정보를 확인합니다.
- **화면 구성**:
  - **스냅샷 뷰어**: 이벤트 전후로 저장된 캡처 여러 장을 ◀ ▶ 로 넘겨 봅니다.
  - **이벤트 정보**: 위험도, 카메라(채널), 발생 시각, AI 설명.
  - **관련 이벤트**: 같은 맥락의 다른 이벤트 목록(클릭 시 해당 상세로 이동).
- **사용 절차**: 스냅샷을 넘겨 상황을 확인하고, 관련 이벤트가 있으면 클릭해 이어서 확인합니다. 좌측 상단 **[← 검색 결과로 돌아가기]** 로 목록으로 복귀합니다.
- **화면 이동**: [← 돌아가기] → `SCH-001`, 관련 이벤트 클릭 → 해당 `SCH-002`.

> [화면 캡처: 클립 상세 — 스냅샷 뷰어, 위험도·시각 정보, 관련 이벤트 목록]

### 3.4 안전 점검

#### 3.4.1 `ZON-001` 구역별 점검 현황
- **목적**: 현장의 **구역별 안전 점검 항목**을 한눈에 봅니다.
- **화면 구성**: 구역 카드 그리드. 각 카드에 구역명, 점검 항목 수, 정적/동적 점검 항목 일부가 표시됩니다.
  - **정적(스냅샷)**: 사람 없이 물체·공간 상태로 판단하는 항목(예: 소화기 가림).
  - **동적(행동)**: 사람의 행동·이벤트로 판단하는 항목(예: 낙상, 보호구 미착용).
- **사용 절차**: 구역 카드를 훑어 어떤 구역에 어떤 점검 항목이 설정돼 있는지 확인합니다.
- **주요 동작/유의사항**: 조회 전용 화면입니다. 구역 등록·항목 편집은 admin 전용(운영자 매뉴얼 참고)입니다. 등록된 구역이 없으면 안내 문구가 표시됩니다.

> [화면 캡처: 구역 — 구역별 점검 항목 카드]

#### 3.4.2 `MNL-001` 적용 체크리스트 조회 (메뉴얼)
- **목적**: 현재 AI가 실제로 사용하는 **확정 체크리스트**를 조회합니다.
- **화면 구성(user 기준)**: “현재 적용 중인 체크리스트” 영역.
  - 상단에 **[전체] / [구역명]** 버튼이 있어, 전체(공통) 또는 특정 구역의 체크리스트를 골라 볼 수 있습니다.
  - 본문에 **STATIC / DYNAMIC** 점검 항목이 표시됩니다.
- **사용 절차**: [전체] 또는 원하는 구역 버튼을 눌러 해당 체크리스트를 확인합니다.
- **주요 동작/유의사항**: user에게는 **조회 전용**으로 표시됩니다. 매뉴얼(PDF) 업로드, 분석, 체크리스트 편집·확정은 **admin 전용**입니다.

> [화면 캡처: 메뉴얼(조회) — 구역 선택 버튼과 STATIC/DYNAMIC 체크리스트]

### 3.5 내 계정

#### 3.5.1 `PRF-001` 프로필
- **목적**: 내 계정 정보를 확인하고, 비밀번호·테마를 바꾸고, 로그아웃합니다.
- **화면 구성**:
  - **인사말·마지막 접속**: “○○○님, …👋” 인사말과 마지막 접속 시각.
  - **계정 정보**: 아바타(이니셜), 아이디, **역할 배지(USER/ADMIN)**, 소속 현장명.
  - **비밀번호 변경**: 현재/새 비밀번호 입력 후 변경.

## 부록 A. 자주 묻는 질문(FAQ)
- **영상이 안 떠요**: 네트워크 또는 카메라 상태 문제일 수 있습니다. 사이드바 상단의 **상태 점등(온라인 n/N)** 으로 채널 상태를 확인하고, 지속되면 운영자에게 문의하세요.

- **다른 현장 화면이 안 보여요**: 정상입니다. 모든 데이터는 **본인 현장**으로 한정됩니다.
- **메뉴얼/구역을 수정하고 싶어요**: 편집은 admin(운영자) 권한이 필요합니다. 운영자에게 요청하세요.
